## 1. 진행 규칙

각 항목은 **현상/근거 확인 → 구현 → 변경 검토 → 필요한 테스트 → 결과·한계 기록** 순서로 처리한다.
자동 테스트 통과, 실제 서버 반영, 실기기 합격은 각각 기록한다. 외부 설정이나 정보가 없는 항목은 완료로 표시하지 않는다.
DB 초기화나 원본 DB 변경으로 오류를 우회하지 않는다. 기존 DB 적용 전에는 백업·복원 리허설과 대상 확인이 필요하다.
