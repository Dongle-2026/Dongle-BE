# 실제 AI 기능 검증 결과 (2026-10-11)

> 실제 기사 3건(한국경제, 아이폰 시험용 복제 DB에서 복사)을 테스트 DB에 넣고, 로컬 모델로 모든 AI 기능을 실행한 뒤
> 생성 결과를 원문과 한 줄씩 대조했다. 운영/복제 DB에는 생성 결과를 쓰지 않았다.

- 모델: qwen3:8b(생성), nomic-embed-text(임베딩) — Apple M2 / 16GB
- 경로: 앱 → Spring 작업 큐(ai_jobs) → Node AI 서비스 → Ollama → 검증 → DB 저장
- 기사: 환율(경제·숫자 多), 건보료 정산(금융·숫자 多), 국민연금 감액 기준(정책·숫자·연도 多)

## 2. 검증 중 발견해 고친 것

| 발견 | 원인 | 조치 |
|---|---|---|
| 퀴즈 정답에 **지어낸 연도** "2025년 6월 17일"(원문은 "6월17일") | 모델이 연도 추측 | 숫자 검증이 정상 차단. 문제는 재시도 지시가 무엇이 틀렸는지 말하지 않아 같은 실수 반복 → **거부된 숫자를 구체적으로 알려 주도록** 수정. 실측: 다음 시도에서 바로 고침 |
| 카드에 **연도 혼동** "2025년 기준 A값 319만원"(원문은 "올해 기준") | 다른 문단 숫자 결합 | 검증이 정상 차단 + 위와 같은 재시도 개선 |
| 퀴즈 정답이 **잘린 숫자** "21만 원"(원문 21만9000 원) | 숫자를 부분 문자열로 비교 | 만·억·조 단위까지 한 덩어리 + 앞뒤 경계 비교로 변경(AI 서비스·Spring 동일) |
| 맞는 해설인데 차단 | 해설이 근거로 표시 안 한 문장의 숫자 인용 | 질문·정답은 근거 문장 기준 유지, **해설은 기사 전체 기준** |
| 퀴즈 생성 시간 초과(180초) | 자기 검증 추가로 호출 증가 | 모델 호출 240초, Spring→AI 540초(작업 리스 10분 이내) |
| 정답이 항상 2번 | 모델 위치 편향 | 저장 전 보기 섞기(이전 수정) |

### 퀴즈 개선 단계별 결과

| 단계 | 환율 | 건보료 | 연금 | 비고 |
|---|---|---|---|---|
| v2 자기 검증 추가 | 시간 초과 | 성공(단, 정답 "21만 원" 잘린 숫자) | 연도 지어냄 차단 | 재시도가 같은 실수 반복 |
| v3 재시도 피드백·숫자 덩어리 비교 | **성공** | 해설 근거 범위로 차단 | 연도 지어냄 차단 | 피드백 후 "21만9000 원"으로 고침 확인 |
| v3 + 해설은 기사 전체 기준 | — | "100분의 100"→"100%" 차단 | 시간 초과 | |
| v4 개념 중심 + 100분의N=N% | **성공**(208초) | **성공**(211초, 실제 작업 큐 경로 218초) | "올해/지난해"→"2024/2025년" 지어냄 차단 | 정답 3/3 원문 일치 |

- 실패한 기사는 퀴즈 영역이 `UNAVAILABLE`로 숨겨지고, 1시간 뒤 다시 조회하면 재생성을 시도한다. 틀린 퀴즈가 저장되지는 않는다.
- 작은 모델이 "숫자 문제는 최대 1개" 같은 지시를 잘 지키지 않는다(건보료는 3문제 모두 숫자).

### 소비 인사이트

합계는 서버 계산(12,000+45,000+1,250=58,250원 일치), 모델은 숫자 없는 조언만 작성. 28초. 금액이 "58250.00원"으로 보이던 표시를 "58,250원"으로 수정.

## 3. 숫자 검증으로 못 잡는 품질 문제 (남은 한계)

| 사례 | 내용 |
|---|---|
| 카드 의미 왜곡 | "A값 319만원에서 519만원으로 상향" — A값이 오른 게 아니라 기준선이 A값+200만원. 숫자는 모두 원문에 있음 |
| 애매한 퀴즈 보기 | 환율 퀴즈 "국고채 금리는 어떤 수준에 도달?" 정답 3.7%(장중), 오답 3.635%(종가)도 원문상 사실. "환율 상승 원인" 오답 "외국인 매도"도 원문상 원인 중 하나 |
| 비슷한 보기 | "5주 전" / "약 5주 만에" |

자기 검증(모델이 자기 문제를 다시 풀기)은 같은 모델이라 이런 애매함을 놓친다. 관리자 검수 없이 공개하기로 했으므로
**앱에 '문제 신고' 버튼**을 두고, 신고가 쌓인 문제를 숨기는 방식을 권장한다(결정 필요).

## 4. 더 좋은 모델

이 Mac(16GB)에서 qwen3.6(36B, 23GB)은 메모리를 넘어 실행이 사실상 불가능하다.
품질을 크게 올리려면 (a) 32GB 이상 장비에서 큰 모델 또는 (b) 외부 AI API(유료)가 필요하다. 현재 구조는 모델 이름만 바꾸면 교체 가능하다.

## 5. 재현 방법

1. 테스트 DB(5433)에 기사 복사 → `POST /api/admin/ai/jobs` {articleId, kind: ARTICLE|CARD|QUIZ}
2. AI 서비스 `npm start`(포트 지정), Spring `--ai-jobs.enabled=true --ai-service.use-stub=false`
3. `ai_jobs` 상태와 `news_summaries`·`card_news_cards`·`quizzes`를 원문과 대조
