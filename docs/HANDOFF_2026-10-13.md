## 3. 프론트에 전달할 것 (그대로 공유)

### 3-1. 백엔드 받기·실행

```text
백엔드는 develop(f9d6379) 기준. PR #5가 main에 merge되면 main도 같다.
1) git pull (develop) → docker compose -f docker-compose.local.yml up -d --build
2) 예전에 띄운 DB가 있으면 추가 테이블 적용(데이터 유지, 여러 번 실행해도 안전):
   docker exec youthletter-postgres sh /docker-entrypoint-initdb.d/02-apply-migrations.sh
3) 샘플 데이터 넣기/보강(중복 없음):
   docker exec -i youthletter-postgres psql -U youthletter -d youthletter -v ON_ERROR_STOP=1 < docker/postgres/03-sample-data.sql
4) 이미 저장된 "경제 …" 제목 정정:
   docker exec youthletter-api java -jar app.jar --ops.run=titles,reclassify --server.port=18082
   (로컬 데이터를 지워도 되면 down -v 후 다시 up이 더 간단)
5) 확인: curl http://localhost:8080/api/health → status UP, database·redis connected
자세한 건 docs/LOCAL_DOCKER_SETUP.md
```

- 계정: `init.sql`의 test@/admin@은 로그인 불가(더미). 앱에서 새로 가입해서 쓴다.
- 로컬은 AI stub 모드다. 크롤링된 실제 기사는 요약·퀴즈가 없고(정상), **화면 시험은 `[샘플]` 기사로** 한다.
